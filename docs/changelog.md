# Changelog

Highlights from recent changes merged into Backfield.

| Date | Changes |
| --- | --- |
| **August 26, 2026** | **Released v0.8.6.** <ul><li>Stylebook connections now maintain one open relationship per record pair and nature, collect supporting article evidence on that relationship, and let editors close or reopen links, review current or former status, and explore a neighborhood graph with a detail panel.</li><li>Automatic connection inference is more reliable and can be configured on Backfield Output with a dedicated model; it defaults off.</li><li>Agate JSON Input accepts uploaded JSON files (up to 20) for small batch runs without cloud storage.</li><li>Backfield Output can save an article even when a flow extracts no entities, such as metadata-only or passthrough pipelines.</li><li>Agate requires Geocode to follow Place Extract on the same branch.</li><li>The API Playground include picker offers <strong>Attached images</strong> on article list and search routes.</li></ul> |
| **August 19, 2026** | **Released v0.8.4.** <ul><li>Article list, search, and entity article feeds can optionally include attached images (up to 10 per article) with <code>include=images</code>.</li><li>S3-ingested articles now record their publication outlet for search and filtering instead of a generic pipeline label.</li><li>Stylebook editors can apply corrected catalog geography onto linked article places so geographic search follows the maintained Stylebook shape.</li><li>The API Playground can remember multiple project API keys in the current browser tab for quick switching.</li><li>Item rerun and replay can reprocess through the currently saved flow when the flow has changed since the original run.</li><li>AI model presets in organization settings are generated from the LiteLLM catalog so current flagship models appear without waiting for a product release.</li></ul> |
| **August 14, 2026** | **Released v0.8.3.** <ul><li>Stylebook canonical records now store typed attributes—text, number, or yes/no values—instead of freeform metadata entries.</li><li>The public API returns canonical attributes on entity detail responses and supports attribute filters on list and search routes.</li><li>Organization administrators can edit a member's display name and role and re-enable a disabled account.</li><li>Stylebook home statistics, project scope selection, and unlinking the last mention from a canonical record behave more reliably.</li><li>Entity extraction with GPT-5.6 models is less likely to fail on truncated output.</li></ul> |
| **August 11, 2026** | **Released v0.8.2.** <ul><li>Organization administrators can configure project webhooks that send signed notifications when flows finish, articles change, or Stylebook canonical records update.</li><li>A durable project event feed helps receivers recover missed webhook deliveries.</li><li>Fixed dropdown and select menus appearing behind dialog overlays.</li></ul> |
| **August 9, 2026** | **Released v0.8.1.** <ul><li>Organization administrators can set a default map view used when maps have nothing else to center on.</li><li>Organization administrators can delete workspaces and projects after typing the name to confirm; the default project and workspaces that contain it cannot be removed.</li><li>Improved Stylebook candidate review and project pages, including the assigned Stylebook shown under the project title.</li><li>Public API routes that filter by mention role now accept multiple <code>nature</code> values (OR).</li><li>Renamed the S3 Input control to “Reprocess completed files” for clarity.</li></ul> |
| **August 8, 2026** | **Released v0.8.0.** <ul><li>Added Document Chunker so long documents can run safely through entity extraction with merged, grounded results.</li><li>Added the signed-in API Playground for exploring and testing the public API.</li><li>Introduced organization sessions, a left-rail organization switcher, and project-scoped Stylebook assignments.</li><li>Added a combined Stylebook candidate inbox, S3 reprocess controls, and project-scoped ingestion tracking.</li><li>Improved geocoding, canonical identity persistence, multi-workspace handling, and API key access rules.</li></ul> |
| **July 31, 2026** | <ul><li>Added explicit organization sessions, organization-scoped routes, and trusted organization provisioning.</li><li>Made each project's Stylebook assignment authoritative, with a Stylebook choice during project creation.</li><li>Added a combined Stylebook candidate inbox across accessible projects.</li><li>Restricted project API keys to public endpoints and current user access.</li><li>Scoped S3 ingestion-ledger records by project.</li></ul> |
| **July 30, 2026** | <ul><li>Upgraded LiteLLM and refreshed curated model options.</li><li>Kept the Stylebook navigation current after catalog changes.</li></ul> |
| **July 29, 2026** | <ul><li>Added an S3 Input idempotency ledger so unchanged files are not processed again.</li><li>Added clearer already-processed states and a deliberate reprocess option.</li><li>Improved place-and-street co-mention handling.</li></ul> |
| **July 28, 2026** | <ul><li>Added CloudWatch application metrics for Backfield Cloud.</li></ul> |
| **July 26, 2026** | <ul><li>Improved multi-workspace behavior.</li><li>Improved geocoding recall and precision across place types.</li></ul> |

| **July 21, 2026** | <ul><li>Improved Stylebook Review status and table behavior.</li><li>Added friendly 404 pages across Backfield applications.</li><li>Improved geocoding for venues, countries, and named places.</li></ul> |
| **July 20, 2026** | <ul><li>Made large-run finalization and cancellation safer.</li><li>Fixed cleanup AI review credential resolution.</li><li>Required authentication before opening the API Playground.</li></ul> |
