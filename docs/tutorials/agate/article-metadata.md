# Add article metadata

Classify articles with consistent editorial categories that can support
filtering, analysis, and downstream products.

!!! note "Tutorial outline"
    Detailed steps, sample taxonomy choices, and screenshots are still to come.

## You'll learn

- The difference between article metadata and canonical Stylebook metadata.
- How topic, format, subject, scope, timeframe, user need, and custom
  categories differ.
- How rationale and confidence help an editor review a classification.
- How metadata becomes searchable through Backfield API.

## Before you begin

Use a project with an enabled generative model and a flow that accepts article
text.

## Planned walkthrough

1. Add **Article Metadata** to a flow.
2. Choose a small set of categories that answer a real editorial question.
3. Review the node prompt and model selection.
4. Run several articles with intentionally different coverage.
5. Inspect values, rationale, and confidence on the processed item's **Meta**
   tab.
6. Correct, add, and remove one classification.
7. Confirm the reviewed values through the API Playground.
