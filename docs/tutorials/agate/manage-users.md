# Manage users and access

Create an organization user, choose their role, and give them the workspace and
Stylebook access required for their work.

!!! note "Tutorial outline"
    Detailed steps and screenshots are still to come.

## You'll learn

- The difference between a member and an organization administrator.
- How workspace access controls which projects a member can open.
- How Stylebook editing permission is assigned separately.
- How to disable access without deleting editorial history.

## Before you begin

You must be an organization administrator. Decide which workspaces and
Stylebooks the new user needs before creating the account.

## Planned walkthrough

1. Open **Users** from organization settings.
2. Add a user with an email, display name, temporary password, and role.
3. Assign the complete set of workspaces the member may access.
4. Assign editing permission for the appropriate Stylebooks.
5. Sign in as the new user and complete the required password change.
6. Verify that expected projects are visible and unassigned projects are not.
7. Change a role or access set, then disable the account.
