# Review and correct processed items

Compare a flow's output with the source article and save article-specific
corrections without silently rewriting canonical Stylebook knowledge.

!!! note "Tutorial outline"
    Detailed steps and screenshots are still to come.

## You'll learn

- What appears on the Info, Places, People, Organizations, Images, Meta,
  Custom, and JSON tabs.
- How evidence highlighting connects a result to source text.
- How the review overlay preserves original machine output.
- Which changes belong in Agate and which belong in Stylebook.

## Before you begin

Complete a flow run that produces people, organizations, places, and article
metadata. Use an item with at least one intentional error or omission.

## Planned walkthrough

1. Open a processed item from its run.
2. Correct an article field on **Info**.
3. Edit an entity field and its evidence occurrence.
4. Add a missed person or place by selecting supporting text.
5. Remove an unsupported extraction.
6. Adjust location geography or choose **No geography**.
7. Correct an article metadata value.
8. Compare Original and Reviewed output on **JSON**, then download the reviewed
   version.
9. Open a linked canonical record without changing its identity from Agate.
