# Search project data

Use text, semantic, metadata, and geographic query tools to answer different
questions about a project's processed content.

!!! note "Tutorial outline"
    Detailed examples and interpretation guidance are still to come.

## You'll learn

- When direct filters are more appropriate than semantic search.
- How semantic search differs from canonical text lookup.
- How metadata and geographic constraints narrow article sets.
- Why an empty result can be correct rather than an API failure.

## Before you begin

Use a project with several Backfield Output articles, semantic embeddings,
article metadata, and geocoded locations. Create a project API key.

## Planned walkthrough

1. Search article text or entities for a known term.
2. Run a semantic search for a concept not stated verbatim.
3. Filter articles by article metadata.
4. Query articles associated with a canonical.
5. Find geographic coverage near a point or inside a cell.
6. Combine constraints and compare result sets.
7. Inspect scores, pagination, and empty results.
