# Manage canonical connections

Create and maintain directed relationships between canonical people,
organizations, and locations.

!!! note "Tutorial outline"
    Detailed steps and screenshots are still to come.

## You'll learn

- Why connection direction changes the meaning.
- How a normalized nature and a readable description complement each other.
- How manual and automatically inferred connections differ.
- How project evidence can support a Stylebook-wide relationship.

## Before you begin

You need editing access and two existing canonical records. Write the intended
relationship as a plain sentence before choosing its direction.

## Planned walkthrough

1. Open the source canonical's **Connections** area.
2. Search for and select the target canonical.
3. Add a relationship nature and description.
4. Verify the from/to direction in list and graph views.
5. Inspect stored evidence on an inferred connection.
6. Edit the wording and remove an incorrect connection.
7. Confirm that project evidence filters do not hide Stylebook-wide connection
   metadata.
