# Create and edit canonical records

Create a canonical manually and maintain its identity, aliases, metadata,
geography, and article evidence.

!!! note "Tutorial outline"
    Detailed steps and screenshots are still to come.

## You'll learn

- Which fields define people, organizations, and locations.
- How canonical details differ from article-specific evidence.
- How to add or correct point, line, and area geography.
- What happens when evidence is moved, unlinked, or leaves a record empty.

## Before you begin

You need editing access to the Stylebook. Choose a real-world identity with
enough trusted information to distinguish it from similar records.

## Planned walkthrough

1. Search for an existing canonical before creating a new one.
2. Create a person, organization, or location manually.
3. Edit its primary details and trusted aliases.
4. Add, edit, and remove a canonical Meta item.
5. For a location, draw or adjust point, line, or area geography.
6. Inspect mentions and filter article evidence by project.
7. Move incorrectly linked evidence to another canonical.
8. Review deletion safeguards for empty and non-empty records.
