# Import canonical records

Create canonical locations from GeoJSON or canonical people and organizations
from CSV files.

!!! note "Tutorial outline"
    Detailed templates, validation examples, and screenshots are still to come.

## You'll learn

- Which import format belongs to each canonical type.
- How imported canonicals differ from article evidence and candidate records.
- How to prepare names, types, affiliations, addresses, and geometry.
- How to inspect the result for duplicates after import.

## Before you begin

You need editing access to the destination Stylebook. Start with a small,
reviewable file and keep a copy of the source data.

## Planned walkthrough

1. Choose the destination Stylebook and canonical type.
2. Download or inspect the expected CSV or GeoJSON shape.
3. Normalize required fields and remove empty or duplicate source rows.
4. Preview and validate the import.
5. Resolve row- or feature-level errors.
6. Complete the import and inspect several canonical detail pages.
7. Run duplicate and geography-quality checks.
