# Review candidate queues

Resolve article entities that Backfield could not safely link to an existing
canonical record.

!!! note "Tutorial outline"
    Detailed steps and screenshots are still to come.

## You'll learn

- Why candidate queues span accessible projects assigned to one Stylebook.
- How link, create, and defer decisions differ.
- How review reasons, evidence, suggestions, and editor notes support a choice.
- How AI recommendations remain subject to editorial acceptance.

## Before you begin

You need Stylebook editing access and at least one unresolved location, person,
or organization. If several projects contribute, know which project you intend
to review.

## Planned walkthrough

1. Open a canonical type's **For review** queue.
2. Filter by project and search for a candidate.
3. Expand its evidence and review reasons.
4. Compare suggested canonicals with a manual Stylebook search.
5. Link a strong match.
6. Create a new canonical after reviewing the similar-record warning.
7. Defer an item that should leave the active queue without being linked.
8. Request AI review and accept selected recommendations.
9. Revisit the **Deferred** queue and related-candidate follow-up.
