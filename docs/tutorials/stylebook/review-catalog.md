# Check catalog quality

Run Stylebook Review checks and resolve possible duplicates, mismatches,
questionable records, and geography concerns.

!!! note "Tutorial outline"
    Detailed steps and screenshots are still to come.

## You'll learn

- Why opening Review does not automatically start a check.
- How run status, issue count, freshness, and durable dismissals work.
- When to merge, delete an empty record, keep records separate, or dismiss an
  issue.
- How AI review proposals use the same actions as manual review.

## Before you begin

You need Stylebook editing access. Choose one check with a small number of
issues for the first walkthrough.

## Planned walkthrough

1. Open the Stylebook **Review** tab.
2. Start a duplicate, mismatch, questionable-record, or geography check.
3. Monitor the check and inspect its latest successful result.
4. Open the affected canonical details before deciding.
5. Merge a confirmed duplicate into the correct keeper.
6. Keep separate or dismiss a false positive.
7. Delete an empty questionable record.
8. Request AI review and compare its proposal with the manual evidence.
9. Use **Recent** activity to confirm the decisions.
